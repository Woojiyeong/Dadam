# 🍵 Dadam

> 차를 우리는 과정과 기록을 통해 다도를 쉽고 감각적으로 배울 수 있는 웹 서비스

<br />

## 🔗 배포 링크

👉 [Dadam 바로가기](https://dadam-one.vercel.app)

<br />

## 📌 프로젝트 소개

**Dadam**은 다도를 단순히 정보로 암기하는 것이 아니라,  
사용자가 직접 차의 종류를 선택하고, 물 온도와 우림 시간을 확인하며  
차를 우리는 과정을 체험할 수 있도록 만든 다도 학습 웹사이트입니다.

차를 마신 뒤에는 향, 맛, 기분 등을 기록할 수 있어  
자신만의 다도 경험을 쌓아갈 수 있습니다.

<br />

## ✨ 주요 기능

### 1. 차 종류 선택 기능

사용자는 다양한 차 종류 중 하나를 선택할 수 있습니다.

- 녹차, 홍차, 우롱차 등 차 종류 선택
- 선택한 차에 맞는 정보 제공
- 차별 특징을 직관적으로 학습

<br />

### 2. 차 우리는 과정 가이드

차를 맛있게 우리는 데 필요한 정보를 제공합니다.

- 적절한 물 온도 안내
- 추천 우림 시간 제공
- 차 우리는 순서를 단계별로 확인

<br />

### 3. 다도 기록 저장 기능

차를 마신 뒤 나만의 감상 기록을 남길 수 있습니다.

- 차의 향 기록
- 맛과 느낌 기록
- 마신 후의 기분 기록
- 개인 다도 경험 저장

<br />
